### 为什么需要这份协议（一句话）

GitHub 的默认规则（"inbound = outbound"）只让项目按**当时那份许可证**使用你的贡献,不包含
"换成别的许可证"的权利。第 2.3 条把这条补上:**你保留版权,项目获得"可按任意许可证
（含商业许可）再许可"的权利**,同时**你的贡献在该许可下永远对所有人可用**（第 2.3 条的"条件"
那一句就是这条保证）。这是 Harmony HA-CLA-I 的标准写法,也是 MySQL / Qt / MongoDB 那类"开源 +
商业授权"双许可项目的通行做法。
